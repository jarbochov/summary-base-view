## What's new

- **Show empty group setting:** Added a view option to show or hide notes with an empty group-by value as an `(Empty)` row. Footer totals now always match the rows shown in the table.
- **Click a group row to open its notes:** Clicking a group row (or pressing Enter/Space) opens a menu of the notes in that group.
- **Delete custom summaries:** Added a Delete button when editing a custom summary formula.
- **Double-click column resizer to auto-fit:** Double-clicking a column edge resizes it to fit its contents, and dragging now updates widths smoothly without rebuilding the table.

## Fixes

- Embedded and unfocused Bases now read and save custom summaries reliably.
- Numeric, decimal, negative, date, and duration columns sort in proper value order with empty cells at the bottom, and `Count`/duplicate column sorts persist across reloads.
- Reordering properties in the Properties menu now updates summary column order, and scroll position is preserved across updates.
- Summary picker search auto-focuses, supports Enter to pick or create a formula, and includes `Stddev` in the formula presets.
- Keyboard sorting on column headers, `1 group` singular grammar, and minor menu/modal polish.
