## Fixes

- **Editing a summary formula now saves (#1).** Choosing *Edit summary* on a preset such as Average and changing `round(2)` to `round(0)` failed with an error. Bases that contain an empty inline `summaries: {}` map had a second `summaries:` key written next to it, which produced invalid YAML. The existing empty map is now filled in place, and a clear "Could not save" notice appears if the Base uses an inline map that cannot be updated safely.
- **The formula editor cursor is now visible (#1).** The text cursor in the summary formula editor was almost invisible. It is now a 2px line in the normal text colour, and selected text has a visible highlight.

## Documentation

- Demo screenshots were retaken in Obsidian's default theme, cropped to the sizes Obsidian recommends (desktop 1200×800, mobile 900×1600) and with less empty space.
