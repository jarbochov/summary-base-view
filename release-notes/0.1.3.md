## What's new

### Copy as Markdown table
The results menu (the count button above the table) now has **Copy as Markdown table** next to the CSV options. It copies the grouped summary as a pipe-delimited Markdown table you can paste straight into a note. Pipes and backslashes in values are escaped and line breaks are flattened so the table stays valid.

The CSV items were renamed for clarity:
- **Copy as CSV** (previously "Copy to clipboard")
- **Copy as Markdown table** (new)
- **Export CSV...**

## Fixes

### Copy actions showed "copied" but pasted the previous clipboard contents
Symptom: choosing a copy action displayed the "Summary copied to clipboard" notice, but pasting produced whatever was on the clipboard before.

Cause: the web clipboard API (`navigator.clipboard.writeText`) can resolve successfully without writing anything when the window has no user activation.

Fix: on desktop, copying now uses Electron's clipboard directly, with the web clipboard API as a fallback (and on mobile). The notice now reports failure if neither path works.

If you have a Summary tab open from before updating, close and reopen it so the new code is used.

## Notes
- Clipboard is only written when you choose a copy action; it is never read.
- Plugin folders that are symlinks do not sync to mobile. Install from the release (or copy `main.js`, `manifest.json`, `styles.css` into the plugin folder) so sync tools see real files.
